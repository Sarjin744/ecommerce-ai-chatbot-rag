Aim:

To build an AI-powered E-Commerce Chatbot using Retrieval-Augmented Generation (RAG) with Ollama.

Problem Statement:

Design and develop a modular Retrieval-Augmented Generation (RAG) based e-commerce chatbot using Ollama. The chatbot should answer FAQs, recommend products, answer product-specific questions, summarize customer reviews, and intelligently route user queries using an LLM-based intent detector.

Software Requirements:

Software Version
Python 3.11.9
Ollama 0.3.14 (Model: Qwen2:0.5b / Qwen)
VS Code 1.94.0
Pandas 3.1.0
Sentence Transformers / Scikit-Learn 1.9.1

Dataset Description:

Dataset Purpose
Products Contains information about products (Product ID, Product Name, Brand, Category, Price, and Specifications). This dataset helps the chatbot answer product-related queries and execute TF-IDF feature recommendations.
FAQs Contains frequently asked questions and verified answers regarding shipping, order tracking, cancellation, returns, refunds, payment methods, and warranty.
Reviews Contains customer opinions and ratings across various product categories used for sentiment analysis (Positive, Negative, Neutral) and customer consensus summarization.

System Architecture:

System Flow Architecture Diagram

[User Query] → [Intent Classification Engine (Ollama Qwen / Rules)]
↓
• FAQ Intent → [Semantic Search Engine (Embeddings & Cosine Similarity)] → [FAQ Answer]
• Recommendation Intent → [TF-IDF Keyword & Price Filter Engine] → [Ranked Products]
• Product QA Intent → [RAG Context Specs Retrieval + Qwen LLM] → [Technical Answer]
• Sentiment Intent → [Customer Review Mining & Sentiment Scoring] → [Consensus Breakdown]
↓
[Unified Chatbot Pipeline] → [Display Response to User]

Module Design:

Module Responsibility
FAQ Module Encodes questions into vector embeddings and performs Cosine Similarity search against pre-stored FAQ vectors to retrieve answers to paraphrased customer queries.
Recommendation Module Computes TF-IDF term weights from product specifications, filters by price budget constraints, and ranks matching products by cosine similarity.
Product Module Implements Retrieval-Augmented Generation (RAG) by retrieving exact product specifications and generating natural language answers using local Qwen.
Review Module Analyzes customer reviews, categorizes feedback into positive, negative, and neutral polarities, and calculates overall consumer consensus.
Intent Module Classifies incoming user queries into FAQ, Product Recommendation, Product QA, or Sentiment Analysis intents.
Chatbot Central orchestrator coordinating data flow between sub-modules, error handling, session persistence, and UI rendering.
